# ModelScope Canary Test Report

The authoritative commands, clean-environment results, artifact sizes, protocol timings, RSS measurements, and
unverified external steps for this release are recorded in `MODELSCOPE_CANARY_RELEASE.md`. Python 3.10, 3.11, and
3.12 each passed 15 wheel-only canary tests and the complete MCP STDIO lifecycle. Historical six-tool and HTTP test
claims do not apply to the canary wheel. The <2 second initialize target was not met and is explicitly reported.
